## Technical Artifacts Summary

The primary technical showcase in this ePortfolio centers around **My Weight Tracker App**, a native Android application developed in Java using Android Studio. Originally created during my mobile architecture coursework, this application was systematically enhanced across three primary categories:

1. **Software Design & Engineering:** Refactored application UI architecture, updated activity lifecycles, and resolved Android theme dependencies (`MaterialCardView` compatibility).
2. **Algorithms & Data Structures:** Enhanced data display pipelines with chronological sorting algorithms and optimized reactive data binding using `LiveData` and `ViewModel`.
3. **Databases:** Implemented Room SQLite persistence, structured relational tables (`users` and `weight_entries`), engineered asynchronous DAO queries, and configured safe schema migration strategies.
